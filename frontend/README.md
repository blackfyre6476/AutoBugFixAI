# AutoFix AI Frontend (`frontend/`)

Next.js + React + Tailwind CSS dashboard UI for AutoFix AI.

## Features
- **Live Backend Polling**: Continuously checks `/api/v1/health` FastAPI endpoint.
- **Modular Component Overview**: Visual cards representing agents, sandbox runner, and LLM integrations.
- **Dark Mode Glassmorphism Theme**: Custom Tailwind CSS design system with HSL accent colors and micro-animations.

## Local Running
```bash
npm install
npm run dev
```
Access at `http://localhost:3000`.
